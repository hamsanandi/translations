# 📚 Translations 

This repository contains translations by @hamsanandi.
Its purpose is to organize translations by language and make them easy to browse/update, and expand over time.

## 🌐 Live Site

You can view the compositions here:
👉 https://hamsanandi.github.io/translations/

## 📜 Contents

The site includes:

- Translations, many a times including the original verses (HTML format)
- Structured presentation for easy reading and reference
- Individual pages for each work
